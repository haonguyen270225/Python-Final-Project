## 📌 Quy tắc chung

- Sử dụng tiếng Anh cho các từ khóa phân loại commit như `Update`, `Add`, `Remove`.
- Ghi rõ lần cập nhật, người thực hiện và ngày cập nhật khi mẫu yêu cầu.
- Mô tả ngắn gọn, cụ thể những nội dung đã thêm, sửa hoặc xóa.
- Định dạng ngày thống nhất: `DD-MM-YYYY`.
- Không sử dụng cùng một số thứ tự cho những lần cập nhật khác nhau trong cùng một nhóm.

## 1. Cập nhật thư mục `asset`

**Áp dụng khi:** Thêm dữ liệu, hình ảnh, tài nguyên hoặc chỉnh sửa nội dung trong thư mục `asset`.

**Cú pháp:**

```text
Update folder asset - Lần thứ [N] : DD-MM-YYYY
info: [Mô tả dữ liệu đã thêm hoặc chỉnh sửa]
```

**Ví dụ:**

```text
Update folder asset - Lần thứ 1 : 16-10-2026
info: Thêm ảnh tiền giấy VND, USD và CNY phục vụ huấn luyện mô hình.
```

## 2. Cập nhật thư mục `document`

**Áp dụng khi:** Thêm mới hoặc chỉnh sửa tài liệu trong thư mục `document`.

**Cú pháp:**

```text
Update folder document - Lần thứ [N] : DD-MM-YYYY
info: [Mô tả tài liệu đã thêm hoặc chỉnh sửa]
```

**Ví dụ:**

```text
Update folder document - Lần thứ 1 : 16-10-2026
info: Bổ sung tài liệu mô tả quy trình xử lý ảnh bằng OpenCV.
```

## 3. Cập nhật mã nguồn dự án

**Áp dụng khi:** Thêm mới, chỉnh sửa, cập nhật hoặc xóa mã nguồn và chức năng của dự án.

**Cú pháp:**

```text
[Update]/[Add]/[Remove]/[Fix] - Lần thứ [N] : [Tên người cập nhật] : DD-MM-YYYY
info: [Mô tả chức năng đã thêm, sửa, cập nhật hoặc xóa]
```

**Ví dụ:**

```text
[Add] - Lần thứ 1 : Nhat Hao : 16-10-2026
info: Thêm chức năng đọc ảnh đầu vào và chuyển ảnh sang ảnh xám bằng OpenCV.
```

```text
[Fix] - Lần thứ 2 : Nhat Hao : 17-10-2026
info: Sửa lỗi xử lý ảnh khi đường dẫn đầu vào không tồn tại.
```

## 4. Cập nhật file `README.md`

**Áp dụng khi:** Chỉnh sửa nội dung hướng dẫn, mô tả dự án, cách cài đặt hoặc tài liệu trong file README.

**Cú pháp:**

```text
Update file README.md - Lần thứ [N] : DD-MM-YYYY
info: [Mô tả nội dung đã thêm hoặc chỉnh sửa]
```

**Ví dụ:**

```text
Update file README.md - Lần thứ 1 : 16-10-2026
info: Bổ sung phần giới thiệu dự án, hướng dẫn cài đặt thư viện và cách chạy chương trình.
```

## 5. Cập nhật code

**Trạng thái:** Chưa áp dụng — sẽ bổ sung quy tắc sau.

Khi thống nhất quy tắc dành riêng cho việc cập nhật code, bổ sung cú pháp và ví dụ tại mục này.

---

## ⚠️ Lưu ý

- `[N]` là số thứ tự của lần cập nhật.
- `[Tên người cập nhật]` nên sử dụng tên hoặc username đã thống nhất trong nhóm.
- Phần `info` cần mô tả thay đổi thực tế, tránh ghi chung chung như “sửa lỗi” hoặc “cập nhật dự án”.
- Chỉ sử dụng `[Add]`, `[Update]`, `[Remove]` hoặc `[Fix]` phù hợp với thay đổi thực tế.
- Nếu một commit thay đổi nhiều loại nội dung, hãy chọn loại chính hoặc tách thành nhiều commit để lịch sử dễ theo dõi.
